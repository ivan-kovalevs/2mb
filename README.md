# 2 МБ — версія для затвердження

Автономний статичний сайт без редактора. Збережений контент: редакція 96.
Фото, шрифти та тексти включені. База даних і тестовий сервер не потрібні.

## GitHub Pages

У Settings → Pages оберіть Source: GitHub Actions. Workflow публікує сайт після push у main.
GitHub Pages робить сайт доступним відвідувачам; видимість репозиторію задається окремо.

## Контент

Тексти, посилання та фінальні адреси фото вже записані в index.html: заглушки не підміняються після відкриття сторінки.
content-snapshot.js містить дані вакансій і біографій для модальних вікон.
content-runtime.js підключає тільки взаємодію з картками; інтерфейсу редагування та API запису немає.
Робоча копія з редактором зберігається окремо.
